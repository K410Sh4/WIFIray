# WIFIray — ESPhub Zero

Repositório independente de implementação do radar CSI com ESP32-S3 N16R8, ESP32-C6, ESP32 DevKit V1 e Android. Código de laboratório: builds nativos e testes não equivalem a validação física.

## Estado

O Marco 4 está sendo auditado e compilado neste repositório. Sem credenciais de dispositivo versionadas; não grave BINs sem verificar modelo/flash e efetuar backup. O repositório está público: **não publique chaves ou senhas**.

A entrega só será considerada aprovada quando a matriz de três firmwares, o APK e testes de qualidade completarem com sucesso. Não afirmar detecção de pessoas, localização ou imagem corporal sem validação experimental.
